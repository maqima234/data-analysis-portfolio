# 个人信用违约预测与评分卡模型

基于 15 万条公开个人信贷记录（Kaggle *Give Me Some Credit*），用 Python 完成从数据清洗、单调 WOE 分箱、IV/共线性筛选，到逻辑回归评分卡、交叉验证、XGBoost 效果参照、评分卡单调性验证与阈值业务分析的完整银行风控建模流程。

---

## 一、项目背景

模拟银行信用卡中心贷前审批场景：用历史客户的信贷数据与违约标签，构建一个**每一分都可解释**的信用评分模型，输出标准评分卡辅助审批决策。

**模型选型：** 主模型用逻辑回归而非 XGBoost——银行风控受监管要求，评分扣在哪一项、为什么扣都必须能向业务和合规解释；XGBoost 仅作为效果上限参照，用来论证"选逻辑回归是可解释性的主动取舍，而非效果偷懒"。

---

## 二、数据概况

| 项目 | 说明 |
|---|---|
| 数据来源 | Kaggle：Give Me Some Credit（天池为转载） |
| 原始样本 | 150,000 条 |
| 清洗后样本 | 123,584 条 |
| 特征变量 | 10 个（循环贷使用率、年龄、月收入、负债率、三类逾期次数等） |
| 目标变量 | SeriousDlqin2yrs（未来两年是否逾期 90 天以上） |
| 违约率 | 6.79%（类别不平衡，属典型风控场景） |

---

## 三、建模流程

### 1. 数据清洗
- 删除逻辑异常：年龄 ≤ 0、循环贷使用率 > 13、负债率 > 50；
- **剔除编码脏值 96/98**：三个逾期次数字段出现 96、98（现实中不可能逾期近百次），且为同一批 260 条记录三字段同时异常，属损坏数据，直接剔除；
- 月收入、抚养人数缺失用中位数填补；月收入按 99 分位截尾（原始存在 300 万的脏值）。

### 2. 关键数据质量排查：三个逾期变量的「伪共线」
三个逾期次数变量在原始数据上两两相关系数高达 0.98，看似严重共线、不能同时入模。排查发现这是 96/98 脏值造成的假象——同一条损坏记录的三个字段被同时写成 98，极端杠杆点把皮尔逊相关系数人为抬高。**剔除脏值后相关系数降到 0.2~0.3**，三者刻画的是不同逾期阶段（30-59 天 / 60-89 天 / 90 天以上），可以同时入模。

### 3. 单调 WOE 分箱 + IV 筛选
- 连续变量等频初箱、有序离散变量（逾期次数等）按取值分箱，再用贪心相邻合并强制 **WOE 单调**（评分卡最重要的约束，保证方向符合业务直觉）；
- IV > 0.02 初筛，再做共线性筛选（|相关系数|>0.8 时保留 IV 更高者）作为防线；
- 最终 8 个变量入模，最强信号为循环贷使用率（IV≈1.02）与 90 天以上逾期次数（IV≈0.80）。

### 4. 模型与验证
- 分层切分 训练:测试 = 7:3；
- 5 折分层交叉验证评估稳定性；
- 逻辑回归为主模型，XGBoost 作效果上限参照；
- 数据无申请时间字段、无法做严格跨时间 OOT，用 200 次 bootstrap 估计测试集 AUC 的 95% 置信区间近似稳定性（局限已如实说明）。

### 5. 评分卡与业务分析
- 基准分 600、PDO=50（odds 每翻倍扣 50 分），回归系数 × WOE 转为各分箱加减分值，输出 `scorecard.csv`；
- **评分卡单调性验证**：测试集按得分十等分，违约率从最低分段 35.8% 单调降到最高分段 0.5%；
- **阈值-业务成本分析**：给出不同分数阈值下的拒绝率与被拒客户坏账率，供在"获客规模 vs 坏账损失"间权衡（如拒绝率 30% 时，被拒客群坏账率约 18%）。

## 四、模型结果

| 指标 | 结果 |
|---|---|
| 5 折 CV AUC | 0.8430 ± 0.0064 |
| 5 折 CV KS | 0.5372 ± 0.0120 |
| 逻辑回归测试集 AUC / KS | 0.8468 / 0.5367 |
| XGBoost 测试集 AUC（上限参照） | 0.8555 |
| bootstrap AUC 95%CI | [0.8385, 0.8555] |
| 评分卡单调性 | 最低分段违约率 35.8% → 最高分段 0.5%，严格单调 |

逻辑回归与 XGBoost 效果非常接近，但前者每一分都可归因，满足监管可解释要求。

## 八、已知局限与后续方向

- 数据无申请时间字段，无法做跨时间 OOT 验证与 PSI 群体稳定性监控，目前以 bootstrap 近似，后续可补时间维度样本；
- 违约率 6.79% 属不平衡样本，后续可讨论好坏样本抽样后的先验概率校准；
- 可进一步做特征衍生（如总逾期次数、使用率分档）与概率校准（预测 PD vs 实际违约率）。
