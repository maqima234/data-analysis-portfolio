# 电商平台用户消费行为诊断分析

基于巴西 Olist 电商平台 9 张业务表、160 万+条记录完成分析，回答三个问题：

1. **GMV 增长来自哪里？** — 量价拆解 → 复购诊断 → 品类贡献 → 地区集中度
2. **用户质量怎么样？** — 购买频次 → 用户价值分层（R/M）→ 贡献帕累托 → 高价值画像
3. **什么因素影响评分？** — 物流全链路 → 延迟 vs 评分相关性 → 地区/品类风险定位 → 剂量反应

**技术栈：MySQL / Python (pandas, matplotlib) / Excel**

## 核心发现

- **复购率极低**：96478 个客户每人只完成过一次交易
- **GMV 由订单量驱动**：客单价稳定在 ~133 BRL，增长依赖新客获取
- **物流延迟与低评分高度相关**：延迟订单差评率 54% vs 准时 9.2%，延迟每增加一周差评率翻倍
- **地区高度集中**：SP 一州占 38.3% GMV，Top 5 州占 73.9%
- **物流延迟呈地区/品类差异**：AL 州延迟率 23.4%，audio 品类延迟率 12.5%

## 业务建议（发现 → 动作）

| 维度 | 分析发现 | 建议动作 | 预期效果 |
|---|---|---|---|
| 用户 | 100% 一次性用户，无复购 | 新客营销转向复购运营：首购后 7/30/90 天触达召回（品类关联推荐 + 优惠券） | 复购率从 0% 起步，GMV 直接受益 |
| 物流 | 延迟订单差评率 54% vs 准时 9.2% | 优先优化高延迟地区（AL/MA）物流运力或调整预计时间；对 audio 等高延迟品类提前预警 | 降低差评率，避免差评 → 流失链路 |
| 地区 | SP 一州占 38.3% GMV | SP 州重点投入，同时向 RS/PR/SC 等腰部州试点扩张 | 守住基本盘，降低单一区域风险 |

> 建议均直接对应分析结论：不做无数据支撑的运营动作，优先级上先解决「复购」与「差评」两个会直接流失 GMV 的环节。
