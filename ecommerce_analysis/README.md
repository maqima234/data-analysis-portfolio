# 电商平台用户消费行为诊断分析

基于巴西 Olist 电商平台 9 张业务表、160 万行真实交易数据，围绕**三个业务问题**展开诊断性分析，每个问题遵循「现象 → 拆解 → 归因 → 建议」的分析链路。

**技术栈：MySQL / Python (pandas, matplotlib) / Excel**

---

## 分析框架

```
数据入库与清洗
    ↓
┌─────────────────────────────────────────────────────┐
│  问题一：平台销售增长来自哪里？                        │
│  GMV量价拆解 → 复购诊断 → 品类贡献 → 地区集中度        │
│  → 结论：纯拉新驱动，头部品类+单州集中，无留存机制       │
├─────────────────────────────────────────────────────┤
│  问题二：平台用户质量怎么样？                          │
│  频次分布 → 队列复购 → RFM分层 → 贡献帕累托 → 画像     │
│  → 结论：0%复购率，RFM退化为R+M，Top20%贡献56%GMV     │
├─────────────────────────────────────────────────────┤
│  问题三：什么因素影响用户体验？                        │
│  物流全链路 → 延迟vs评分 → 地区归因 → 品类归因 → 剂量   │
│  → 结论：延迟差评率54% vs 准时9%，AL州/audio品类最差   │
└─────────────────────────────────────────────────────┘
    ↓
综合建议与业务行动项
```

## 核心发现

- **复购率 = 0%**：所有完成交易的客户均未复购，平台本质是获客→转化→流失的漏斗
- **GMV 由订单量驱动**：客单价稳定在 ~133 BRL，增长完全依赖新客获取量
- **延迟是差评的核心归因**：延迟订单差评率 54% vs 准时 9.2%，延迟每增加一周差评率翻倍
- **地区高度集中**：SP 一州占 38.3% GMV，Top 5 州占 73.9%
- **物流延迟呈地区/品类差异**：AL 州延迟率 23.4%，audio 品类延迟率 12.5%
