# 电商平台用户消费行为诊断分析

基于巴西 Olist 电商平台 9 张业务表、160 万行真实交易数据，回答三个具体问题：

1. **GMV 增长来自哪里？** — 量价拆解 → 复购诊断 → 品类贡献 → 地区集中度
2. **用户质量怎么样？** — 购买频次 → RFM 分层 → 贡献帕累托 → 高价值画像
3. **什么因素影响评分？** — 物流全链路 → 延迟 vs 评分归因 → 地区/品类定位 → 剂量反应

**技术栈：MySQL / Python (pandas, matplotlib) / Excel**

## 核心发现

- **复购率为零**：96478 个客户每人只完成过一次交易，无人回头
- **GMV 由订单量驱动**：客单价稳定在 ~133 BRL，增长完全依赖新客获取
- **延迟是差评的核心归因**：延迟订单差评率 54% vs 准时 9.2%，延迟每增加一周差评率翻倍
- **地区高度集中**：SP 一州占 38.3% GMV，Top 5 州占 73.9%
- **物流延迟呈地区/品类差异**：AL 州延迟率 23.4%，audio 品类延迟率 12.5%
